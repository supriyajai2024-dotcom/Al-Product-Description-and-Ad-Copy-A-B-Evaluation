# Google Sheets import instructions

1. Open Google Drive and create a blank spreadsheet.
2. Choose **File → Import → Upload**, select `data/ad_variants.csv`, and import into a new sheet.
3. To use the full workbook, upload `eco_capstone.xlsx` to Drive and open it with Google Sheets. Confirm formulas and charts after conversion; Excel formula/chart compatibility can vary.
4. Rename/confirm sheets: Ad Variants, Survey Responses, Summary Dashboard, Analysis.
5. Add survey responses only after collection. Keep synthetic testing data in a separate file/sheet clearly named SYNTHETIC — TEST ONLY. Never append it to real-response rows.
6. Share the survey using the methodology in `docs/survey_methodology.md`; do not collect email addresses unless required and disclosed.

No Google account integration or live Google Sheets connection was tested or created here.
