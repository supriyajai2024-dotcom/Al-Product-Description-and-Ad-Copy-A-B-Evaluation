# Final demonstration script (4–5 minutes)

“ This capstone asks which AI-written ad copy performs best with real readers, and why. EcoSip Smart Bottle is fictional; its only assumed facts are a reusable bottle for everyday use, suitable for students and office workers, with water-level markings.

I compared three prompting styles—basic, role-based, and few-shot—and produced five concise variants per style. Each has an ID, headline, body, CTA, character count, and model/tool metadata that should be updated if regenerated.

The workbook and Streamlit dashboard organize the ads and calculate votes and average ratings after genuine responses are entered. This project has not collected survey responses: the status is awaiting data, sample size is zero, and there is no winner. The survey instructions target at least 20 volunteers and minimize personal data.

The responsible-AI review checks claims and readability. It is a desk review, not independent external verification. After collecting real responses, I will import them, review valid counts, compare ads and styles, summarize feedback, and report limitations without overstating significance.”
